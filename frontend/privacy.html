Confidentialité

ArcadePipe se joue sans compte et sans inscription. Le jeu n'a pas de serveur : il n'envoie rien, à personne.

Sur ton appareil

Le jeu garde dans le stockage local du navigateur ton classement (pseudo, score, vague et ennemis abattus de tes 10 meilleures parties), le nombre de parties jouées et tes réglages : volumes, son coupé, dernière piste, tir automatique, vitesse du jeu, filtre rétro, panneau replié, langue, dernier pseudo, meilleur score, aide déjà vue. Ils ne quittent pas ton appareil, sauf la langue choisie avec le bouton de langue, qui apparaît dans l'adresse de la page (?lang=fr). Vider les données du site les efface.

Mesure d'audience

Le jeu ne mesure pas l'audience : aucun script de mesure, aucun cookie. Sur itch.io, la page qui accueille le jeu suit les règles d'itch.io.

Questions

Pour toute question, écris à contact@pazpop.net. Le code du jeu est public sur la page GitHub du projet.

Privacy

ArcadePipe needs no account and no sign-up. The game has no server: it sends nothing to anyone.

On your device

The game keeps in the browser's local storage your leaderboard (name, score, wave and enemies destroyed of your 10 best games), the number of games played and your settings: volumes, mute, last track, auto-fire, game speed, retro filter, collapsed panel, language, last player name, best score, whether you have seen the help screen. They never leave your device, except a language picked with the language button, which appears in the page address (?lang=en). Clearing the site's data removes them.

Analytics

The game does not track visits: no analytics script, no cookie. On itch.io, the page that hosts the game follows itch.io's own rules.

Questions

For any question, write to contact@pazpop.net. The game's source code is public on the project's GitHub page.
