Confidentialité

ArcadePipe se joue sans compte et sans inscription. Voici tout ce que le jeu enregistre.

Le classement

Quand un score entre dans le classement, le jeu envoie au serveur le pseudo choisi (8 caractères au plus, « AAA » par défaut), le score, la vague atteinte et le nombre d'ennemis abattus. Le serveur y ajoute la date et l'heure. Ces informations sont publiques, puisque le classement est visible par tous, et sont gardées tant que le score reste parmi les 10 000 meilleurs.

Chaque partie terminée ajoute aussi une unité à un compteur global de parties jouées, sans aucune information sur le joueur.

Adresse IP

Le serveur lit l'adresse IP uniquement pour limiter le nombre de requêtes par minute. Elle est gardée en mémoire une minute et n'est jamais enregistrée.

Mesure d'audience

Sur le site officiel, le jeu peut utiliser Google Analytics pour compter les visites. Rien n'est chargé et aucun cookie n'est déposé avant que tu aies cliqué sur « Accepter » dans le bandeau. Tu peux changer d'avis à tout moment avec le bouton « Cookies » du panneau de réglages : un refus arrête la mesure et efface ses cookies. Les autres versions du jeu (itch.io, copies hébergées par d'autres) n'ont pas de mesure d'audience, sauf si leur hébergeur l'active.

Sur ton appareil

Le jeu garde tes réglages dans le stockage local du navigateur : volumes, son coupé, dernière piste, tir automatique, vitesse du jeu, filtre rétro, panneau replié, langue, dernier pseudo, choix sur les cookies, aide déjà vue. Ils ne quittent pas ton appareil ; vider les données du site les efface.

Faire retirer un score

Pour faire retirer un pseudo ou un score du classement, ou pour toute question, ouvre une demande sur la page GitHub du projet. Le code du jeu et du serveur y est public.

Privacy

ArcadePipe needs no account and no sign-up. Here is everything the game records.

The leaderboard

When a score enters the leaderboard, the game sends the server the chosen name (up to 8 characters, "AAA" by default), the score, the wave reached and the number of enemies destroyed. The server adds the date and time. This information is public, since anyone can see the leaderboard, and it is kept for as long as the score stays among the 10,000 best.

Each finished game also adds one to a global count of games played, with no information about the player.

IP address

The server reads the IP address only to limit the number of requests per minute. It is kept in memory for one minute and never stored.

Analytics

On the official site, the game may use Google Analytics to count visits. Nothing is loaded and no cookie is set until you click "Accept" in the banner. You can change your mind at any time with the "Cookies" button in the settings panel: declining stops the measurement and deletes its cookies. Other versions of the game (itch.io, copies hosted by others) have no analytics unless their host turns it on.

On your device

The game keeps your settings in the browser's local storage: volumes, mute, last track, auto-fire, game speed, retro filter, collapsed panel, language, last name used, cookie choice, help already seen. They never leave your device; clearing the site's data removes them.

Removing a score

To have a name or a score removed from the leaderboard, or for any question, open a request on the project's GitHub page. The code of the game and of the server is public there.
