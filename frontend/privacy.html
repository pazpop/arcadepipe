Confidentialité

ArcadePipe se joue sans compte et sans inscription. Voici tout ce que le jeu enregistre.

Le classement

Quand un score entre dans le classement, le jeu envoie au serveur le pseudo choisi (8 caractères au plus, « AAA » par défaut), le score, la vague atteinte et le nombre d'ennemis abattus. Ces informations sont publiques, puisque le classement est visible par tous. Le serveur y ajoute la date et l'heure, qu'il ne publie pas. Le tout est gardé tant que le score reste parmi les 10 000 meilleurs, puis environ quatre semaines de plus dans les sauvegardes.

Chaque partie terminée ajoute aussi une unité à un compteur global de parties jouées, avec la date et l'heure, sans aucune information sur le joueur.

Adresse IP

Le serveur du classement (arcadepipe.pazpop.net, y compris quand tu joues sur itch.io) lit l'adresse IP uniquement pour limiter le nombre de requêtes par minute et d'envois de scores par jour. Elle est gardée en mémoire un jour au plus et n'est jamais enregistrée.

Mesure d'audience

Sur le site officiel, le jeu peut utiliser Google Analytics, un service de Google, pour compter les visites. Rien n'est chargé et aucun cookie n'est déposé avant que tu aies cliqué sur « Accepter » dans le bandeau. Tu peux changer d'avis à tout moment avec le bouton « Cookies » du panneau de réglages : un refus arrête la mesure et efface ses cookies. Les autres versions du jeu (itch.io, copies hébergées par d'autres) n'ont pas de mesure d'audience, sauf si leur hébergeur l'active.

Sur ton appareil

Le jeu garde tes réglages dans le stockage local du navigateur : volumes, son coupé, dernière piste, tir automatique, vitesse du jeu, filtre rétro, panneau replié, langue, dernier pseudo, meilleur score, choix sur les cookies, aide déjà vue. À part le pseudo envoyé avec un score, ils ne quittent pas ton appareil ; vider les données du site les efface.

Faire retirer un score

Pour faire retirer un pseudo ou un score du classement, ou pour toute question, ouvre une demande sur la page GitHub du projet. Le code du jeu et du serveur y est public.

Privacy

ArcadePipe needs no account and no sign-up. Here is everything the game records.

The leaderboard

When a score enters the leaderboard, the game sends the server the chosen name (up to 8 characters, "AAA" by default), the score, the wave reached and the number of enemies destroyed. This information is public, since anyone can see the leaderboard. The server adds the date and time, which it does not publish. All of it is kept for as long as the score stays in the top 10,000, then about four more weeks in backups.

Each finished game also adds one to a global count of games played, with the date and time and no information about the player.

IP address

The leaderboard server (arcadepipe.pazpop.net, including when you play on itch.io) reads the IP address only to limit the number of requests per minute and the number of score submissions per day. It is kept in memory for one day at most and never written to disk.

Analytics

On the official site, the game may use Google Analytics, a Google service, to count visits. Nothing is loaded and no cookie is set until you click "Accept" in the banner. You can change your mind at any time with the "Cookies" button in the settings panel: declining turns analytics off and deletes its cookies. Other versions of the game (itch.io, copies hosted by others) have no analytics unless their host turns it on.

On your device

The game keeps your settings in the browser's local storage: volumes, mute, last track, auto-fire, game speed, retro filter, collapsed panel, language, last player name, best score, cookie choice, whether you have seen the help screen. Apart from the name sent with a score, they never leave your device; clearing the site's data removes them.

Removing a score

To have a name or a score removed from the leaderboard, or for any other question, open an issue on the project's GitHub page. The game and server source code is public there.
